# AIML-E Grade Card Portal — Frontend

React (Vite) frontend for the AIML-E Grade Card Portal. See the [project README](../README.md) for
what this site is, what data is real vs synthetic, and full run instructions.

Quick start:

```bash
npm install
npm run dev
```

Runs on `http://localhost:5173` and expects the backend (see `../backend`) on `http://localhost:8080`.
